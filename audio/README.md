# 正式音訊與授權

目前僅保留 `audio-core.js` 選取的6首OGG背景音樂與11個OGG音效。停用介面點擊音、其他試聽／音量比較版本及MP3／WAV／FLAC／ZIP已退役。播放、音量、GM試聽、冷暖載入規則不變。

授權、作者、來源URL、原始SHA與匯出SHA保留於 `assets/era-themes/manifest.json`、`assets/battle-themes/manifest.json`、`assets/common-sfx/manifest.json` 及 `assets/manifest.json`。manifest內來源檔名及舊選擇紀錄是歷史provenance，不代表來源檔仍存在或仍為正式資源。CC BY授權與作者記錄不得刪除。

現役檔案選擇由 `scripts/publish-assets.cjs` 的audioSelection驗證；音訊回歸檢查17檔完整性、SFX原始SHA與播放生命週期。原製作／試聽紀錄可由 [清理前audio樹](https://github.com/franksky1207/rpg/tree/c0ec18d686d7111b2e5a7fa380c94653a2b8a2e4/audio) 追溯。
