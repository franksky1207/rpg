# 《文明戰線》三紀元頭部裝備正式美術規則：穿戴時不露臉

生效：2026-10-11。適用於所有 3D 頭部裝備美術、模型製作、資產審查、GM 展示及第 28～40 批後續施工。**這是設計與後續驗收規則，非宣稱現有模型已實作。** 正式名稱以當下 GitHub main 的遊戲資料為唯一真實來源。

## 強制規則

1. 玩家配戴任何正式 `helmet` 槽裝備時，外部鏡頭**不得直接看到清楚的裸露臉部與五官**（眼、鼻、嘴、臉頰、下巴）。不須製作開面罩、透明露臉、露出五官的穿戴款。
2. **不要求所有 helmet 都長得像傳統封閉鋼盔。** 依正式名稱分家族：防護盔／密封盔採完整物理面甲；冠／冕／環／目鏡可用完整不透明能量面、光學遮罩、投影面具、懸浮遮面結構；高維視域／法眼／感知場採非實體維度遮面。頭部輪廓須與名稱的物理/概念語意一致。
3. 能量遮面、半透明造型層仍須確保**玩家臉部無法直接辨識**。不得僅使用一條細光帶而露出大部分臉。
4. 卸下 helmet 後，必須完整恢復第 27 批已接受的人物頭髮、臉、眼、頸；不能永久刪除臉部 mesh、改正式角色骨架或改玩家外觀存檔。
5. 遮蔽以每個 3D 場景 instance 可恢復的網格/材質分區及裝備遮面為主。**不可直接隱藏整個頭顱或整片軀幹**來掩飾缺乏裝備幾何；無法精確遮蔽時先保留安全回退並列為待補。
6. 此規則**只約束頭部裝備的 3D 視覺**，不改 210 個正式名稱、裝備品質、能力、掉落、戰鬥、存檔或 GM 權限。亦不強制讓未穿 helmet 的人物遮臉。

## 適用資料與範圍

- 銀河紀元：`worldmaps-earth.js` 等 10 份 `worldmaps-*.js`，100 套／100 個 helmet 名稱。
- 宇宙紀元：`secondworlddata.js` 的 100 位 Boss 裝備 helmet 名稱。
- 高維紀元：`thirdworldloot.js` 的 10 階 `NAME_ROWS[].helmet`，例如「偏光視域」到「至界無觀」。
- 共計 210 個正式頭部裝備名稱位置。完整模型家族擴充在第 29～30 批，嚴格使用當時正式名稱映射。

## 第 28-C 必先適用的首套正式裝備

銀河紀元「地球戰爭 → 古代科技遺址」（Lv.31～35），正式來源 `worldmaps-earth.js`：
- weapon：古代光刃
- **helmet：遺物守衛盔**
- armor：自律護衛甲
- shoes：遺跡浮行靴
- accessory：古文明鑰印

「遺物守衛盔」必須是**不露臉的古文明守衛型完整面罩**，可用不透明感知面板及青藍能量紋路，但不得直接看到五官。卸裝恢復原人物臉部。不可替換五槽正式名稱，也不可拿沒有遊戲身份的通用科幻裝冒充本套。

## 第 28-C / 29～30 批驗收

- 角色正面、左右側面、背面、俯仰及 idle／頭部轉動時，配戴 helmet 不露臉。
- 空頭盔槽與卸盔後恢復原始頭臉；快速重複穿卸、跨 LOD、正式角色與 GM 正式快照均相容。
- 冠冕、光環、高維類應有**非傳統頭盔**的視覺差異，仍須遮臉；不能用同款普通鋼盔換顏色敷衍。
- 無正式 GLB 時不得宣稱已通過穿戴實測；需等待模型和 Babylon 場景驗收。
