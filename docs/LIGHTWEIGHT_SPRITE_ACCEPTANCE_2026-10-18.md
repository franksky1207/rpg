# 《文明戰線》第7批・輕量戰鬥動畫美術允收新標準（2026-10-18，使用者定稿）

**優先於第7批既有高精度補圖文件與歷史稽核的美術允收條件**，但不取代程式安全、權限、正式戰鬥數值、Actions、Pages或存檔保護。舊報告代表當時依舊標準得出的事實，保留供追溯；其中「逐指遮擋、完全重組」不再是當前必要發布阻擋。適用既有草稿 PR #38；僅更新規格，不宣稱施工已完成。

## 目標與視覺硬性標準
- 核心目標：**角色明顯、六動作清楚、iPhone與一般手機流暢、正式戰鬥正確**。不追求大作級美術、像素級裝甲還原或逐幀手繪。
- 三套定稿主角身份、全罩盔、右向3/4、文明配色、固定代表劍與機動型輪廓保留；高維僅採無披風／無星環／無漂浮星體v2。
- **完整持劍人物圖單層即可作正式Sprite**；候選無武器身體與獨立武器不是強制素材，不強制三套×三張九核心圖；需要更佳視覺時才使用獨立武器。
- 真透明Alpha（不可把白底或棋盤烘焙進正式圖片）與清楚人物輪廓是硬性；但允許一般遊戲尺寸下不可見的光效邊緣差異、握柄／指節／腿甲非像素級一致。必須實際用正式手機顯示尺度判斷「明顯」，不能以原圖放大檢查的微小瑕疵阻擋。
- 避免明顯白框／破洞／裁切／錯誤方向／武器離手飛走／蓋住HP或文字；以穩定、清楚勝於複雜細節。

## 六個基本狀態（不需六張獨立美術圖）
1. 待機：輕微上下浮動。
2. 攻擊：向目標明顯前移／突刺感（可搭簡單光效，但不大量遮輪廓）。
3. 受擊：小幅後仰／短閃。
4. 閃避：短距離側移／殘影。
5. 回位：平滑回到原本戰場位置。
6. 死亡：輕度傾倒與淡出。

全部沿用現役 Presenter／Renderer 事件、時間與狀態生命週期；動畫效果僅渲染，不可多算／漏算任何傷害、回合與結算。

## 分層選用策略
- **優先嘗試三張完整持劍人物圖**→做正式尺寸透明WebP→完成六動作播放測試。
- 候選 `attack-body`、`independent-weapon` 若小尺寸重組改善攻擊辨識度才整合；不要求原座標逐像素拼回完整母圖、不要求前後指節精確遮罩、不必重畫被遮住的腿甲。
- 分層若造成明顯穿插／彆扭，**直接安全回退完整角色單層**，不構成美術不合格。
- 正式採用檔案仍須來源、SHA、尺寸、Alpha、資源版本與可重建資料；只可引用實際存在的新版高維v2素材。

## 不可放寬的工程及產品保護
- 三紀元外觀與裝備／GM隔離；首次轉生前依紀元、轉生後自由切換與帳號隔離／重載／合法匯入、Save Schema17不變。
- 主線／合法副本、現有所有正式玩法及HP／盾／傷害／獎勵／回合／結算不變。
- 極簡、背景／離線／Fast Catch-up、倍速、音樂音效與文字回退不變；手機避免重複解碼、Canvas／RAF／監聽器洩漏或長任務。
- GM動畫測試中心可在隔離環境核對三造型與六狀態，不污染正式存檔。
- 維護資產manifest與快取版本、智慧下載、Release Gate、Pages驗收；以本次實際SHA的Actions證據與公開資源核對，不能拿舊主角的CI通過冒充新版Sprite成功。
- 不以CI模擬冒充iPhone真機發熱；真機觀察保留為之後實際遊玩回報。
- 高維十王Issue #37不在本批；第8批不提前開工。

## 第7批放行判準
**必要**：三套新造型均能在正式動畫模式安全顯示；六狀態可肉眼辨識；手機viewport不明顯裁切／破圖；正常與回退、GM隔離、資源生命週期、正式數值與帳號／存檔保護通過；發布素材可查來源SHA，Actions／Pages驗證符合該SHA。
