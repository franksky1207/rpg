# 全戰鬥動畫定位與連戰停止按鈕・26項統一修正（2026-10-19）

基準 main：`e6c72e055cd009dc90e00a4f49d332545b3a6fbb`。此施工僅處理 UI/DOM 捲動與控制鈕位置；正式戰鬥計算、停止時機、音訊、背景、存檔、三紀元 Sprite 和第12批上挑斬不修改。

## 設計
- 共同 viewport owner：`combat-viewport-coordinator.js`；僅手機且動畫開啟、頁面可見、非極簡/GM背景時生效。僅一個 MutationObserver 與有限的 RAF 安排，不逐幀追蹤。
- 真正目標是正式 `.formal-b-shared-stage`，不是標題/外層 HUD；等待正式動畫 host 解除 hidden 後量測。以 `visualViewport.height/offsetTop` 計算可視區；區塊可完整顯示時不捲動。
- 將正式動畫模式中可停止連戰的原生控制鈕移到舞台之前，沿用所有原本 onclick/disabled/label 及主程式，沒有建立新按鈕或停止 owner。一般文字模式保持舊行為；鏡像戰等不可中止者不新增控制。
- 手機 Safari 實際視窗大小變化、橫向尺寸重新檢查；使用者 touchmove/wheel 後停止搶捲動直到離開戰鬥。背景/極簡/隱藏分頁停止定位。
- 桌機不干預。舞台與背景位置不另改造；舞台原始 Sprite 尺寸及背景裁切由現行第12批正式 renderer/CSS 負責。
- 首次入場/自動換場/異步 host 掛載沿單一 owner；不更改原數值/停止時機。
