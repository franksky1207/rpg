# 《文明戰線》210 套裝備概念圖藝術方向
建立：2026-10-11。屬於**尚待逐套批准的美術引導**，不得改寫正式裝備名稱、紀元設定、掉落或數值。正式名稱／身份以現行 main 的資料 owner 與 `_concept-index.json` 核對；各套人工 notes 優先決定具體設計，與既有正式規格衝突先核對。

## 1. 三紀元美術演進（不等於固定配色）
- **銀河紀元（G001～G100）**：由地球／太陽系可理解的戰術防具與工業製造，逐步到星際與銀河文明特色。依每個大區、地形、科技與正式五槽名稱演進；不能 100 套都沿用地球士兵盔甲只改色。
- **宇宙紀元（U001～U100）**：依每隻正式 Boss 與區域主題設計跨星域結構、能量機制、異文明材質和更大尺度的形態語言；不能只是銀河裝甲更多發光、更多肩甲。維持人物可穿戴性與五槽映射。
- **高維紀元（H01～H10）**：依正式剩餘 HP 裝備名稱分階，允許異象、非連續裝甲、漂浮幾何、光學視域與空間錯影；**不是**固定 Boss 等級，也不是把「視域」「冠冕」硬做成同種金屬頭盔。仍要符合既有完整遮臉與可逆卸除的視覺規範。

## 2. 每套五槽的辨識責任
- **weapon**：與正式名稱相符的刀、刃或其他武器機制、握柄、長度與碰撞比例；整套圖與拆解圖一致。
- **helmet**：依名稱做不同輪廓；在穿戴時必須完整遮住可辨識五官，卸除後回復人物原臉。冠冕、光環、視域須另設真正有效的遮蔽方式，不強制同款封閉鋼盔。
- **armor**：胸背、肩臂、腰胯合理分件，穿脫時不移除身體基底，與鞋槽分界明確，避免一體成形無法混搭。
- **shoes**：左右一組、對地形／推進機制有特徵，與小腿甲裝配界線明確。
- **accessory**：正式名稱對應的可識別裝置／徽記／鑰印／場域，不應每件都只做一般背包；須避免和背甲、武器、動畫碰撞。
- 先有**獨特輪廓**再加材質光效；輪廓一致但顏色不同不算不同套。

## 3. 跨圖一致性、建模可落地
- 同套兩張正式 WebP：`overview-front-side-back.webp` 正／側／背人物；`equipment-five-slots.webp` 五單品與分件結構。單品三視圖應吻合武器長短、頭盔面型、肩寬、背部裝置與鞋子。
- AI 圖可能有不對稱、假接縫、武器左右手誤置、背部飾品重複、文本假字與跨角度誤差；產圖後逐項比對，必要時局部重畫。名稱以正式 notes 為準，不相信圖片內文字。
- 質感可高於實際 GLB 細節預算；後續建模要為桌機與手機建立主次細節、貼圖與 LOD，不承諾每顆螺絲建成幾何。
- 第 27 批人物 53 骨骼、9 掛點、五槽獨立混搭、三 LOD、可逆遮蔽及正式遊戲公式須全部維持；概念圖不得用於要求破壞這些契約。

## 4. 批次驗收方式
- 每十套共通世界觀，但至少在武器、頭盔、甲片主輪廓、鞋子機能、飾品形態等維度體現差異；建議同時觀看該批十張三視圖縮圖比較「輪廓是否撞型」。
- 每套逐項檢查正式五槽、風格、三視圖一致、單品完整、戴盔無臉、縮小後辨識度、可被真實掛載／穿戴；按雙階段 SOP v2.0 記錄自動審查通過／需局部修正／證據不足／退回；不由 CI 或圖片存在單獨批准，不需逐套人工批准。
- G001～G010 為已生成入庫的早期參考，而非所有世界與紀元都須複製的模板；舊第 28-C 低模僅是技術測試，不代表最終藝術品質。
