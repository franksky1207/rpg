# 全紀元五槽裝備設計與技術共用契約 v1｜2026-10-13

本規格依使用者本次正式施工指令建立，適用銀河100、宇宙100、高維10，共210套／1,050個正式映射位置。它是後續設計與交付規範，**不是逐套概念批准，也不表示新遮蔽／混穿功能已實作**。基準main `5a1b219e33e15f313b620bb8d9984eab87bdf810`；新版B方案優先，玩家即時3D、敵人預渲染atlas，GM是唯一開發美術預覽中心。原28-A/B/C及人物基座承接，不重做。

## 1. 身分與三層責任

正式資料owner → `_concept-identities.json`／`_concept-index.json` → 唯讀appearance descriptor → 既有asset registry／loader，是唯一身份鏈。ID、sourceKey、epoch、正式name、slot、region／Boss／HP band、quality與真實來源SHA共同核對；英文slug、圖中文字、本文部件ID不能代替正式身份。1,050是位置數，不要求1,050個字串唯一；宇宙重名仍按正式sourceKey分辨。高維band是剩餘HP名稱階，不能當固定Boss等級。

| 層 | 責任 | 禁止的擴張 |
| --- | --- | --- |
| 人物基底 | 原53骨、9掛點、約1.9m、三LOD、原bind及基底權重 | 為套裝、品質或強化另建整個人物／改原骨架 |
| 五槽裝備 | 獨立部件、形體、同骨架相容裝備權重／rigid pivot、實際覆蓋 | 將整套焊成一件；用G007冒名其他套 |
| 材質／品質／強化／局部特效 | 讀正式快照，有限材質變體與局部FX；缺視覺證據顯示unavailable | 自算戰力、改數值／裝備狀態；每強化級複製完整模型或新戰鬥／音效owner |

三LOD是幾何品質，不等同掉落稀有度。品質／強化視覺規則須另有批准且符合身份映射，不能把當前quality解析偷改為另一種語意。

## 2. 功能歸屬與唯一部件所有權

| slot | 正式中文類別 | 預設所有權／卸裝行為 |
| --- | --- | --- |
| weapon | 武器 | 作用端、握柄、護手、武器自身致動器／能源層。卸裝全部移除，手與其他槽恢復 |
| helmet | 頭盔 | 頭殼、遮面、盔內感測與盔端密封。穿戴完整遮住可辨五官；卸下原臉恢復 |
| armor | 鎧甲 | 胸背肩肘腰胯、大腿及膝防護；必要護領、裙片、**空掛座**。卸甲不留下孤立膝片或甲屬裙 |
| shoes | 鞋子 | 左右雙鞋、鞋底、小腿／腳踝護片、推進器。左右一槽同步；不得帶第二套膝甲 |
| accessory | 飾品 | 獨立背部裝置／核心／框／自帶支架或功能性其他位置裝置。卸飾品移除完整裝置，已穿armor的空座可留 |

位置不等於槽位。頸部裝置按功能指定唯一owner：盔端呼吸器可helmet、衣領隔熱可armor、獨立導航器可accessory；接口連接段也須唯一owner。相接兩槽缺一時不能殘留懸空跨槽管線。armor無飾品時仍完整；飾品無armor時可用原背掛點及自帶支架，不依賴整套。

預設膝歸armor、脛踝歸shoes；柔性衣料內襯可延伸，但不複製另一槽完整硬殼。關節接縫可露出設計性基底服，不能以硬殼重疊／大面積遮蔽冒充銜接。例外需逐件記錄理由、owner、接口、覆蓋、支持组合與回退，不自行變更正式slot。

高維非實體甲、漂浮片、冠冕、光環、場投影皆允許。漂浮片仍有唯一owner／既有骨或掛點的local基準、有限空間包絡／可取消視覺生命週期；卸槽全部撤除。冠冕／光環不強制金屬盔，但需要本槽的有效不透明遮面方案，不能隱藏整頭或用滿屏光掩臉。能源甲只有實際覆蓋面可申請遮蔽；非實體效果不自動擁有整軀幹遮蔽。

後續每套notes／模型交付附以下資料表；這是**設計資料欄位，不是已上線registry schema**，本次不新增Runtime欄位或假assetId。

| 欄位 | 必填含義／驗證 |

| partId／ownerSlot | 套內穩定唯一，如`g007:shoes:shin.L`；左右、內襯／硬板各別；不是新物品身份 |

| attachment | 真掛點／骨映射、pivot、座標制、local transform、允許偏移範圍與依據 |
| interface／envelope | 膝—脛、頸—領、肩—背、裙—腿接口剖面／關節活動包絡；跨族相容或明確限制 |

local偏移以裝備子層完成，不能改九掛點矩陣。數值公尺／弧度、bounds与容許範圍由Blender真測量填寫，圖面未量測時標「待量測」，不能虛構通用毫米數。沿用Blender公尺+Z up/-Y forward，glTF公尺+Y up/+Z forward、scale=[1,1,1]及原轉換管線。裝備蒙皮可用相容53骨權重，不得改人物原權重；rigid武器／飾品不重複人物動畫或骨架。

## 4. 任意五槽混穿與遮蔽契約

混穿是設計要求，不能預設只穿整套。建立接口族與空間包絡复用測試，不產生210套全部笛卡兒積的專屬模型。最少覆蓋空槽、各單槽、全槽、同套子集合、兩套真模型互混、各接口族極值／跨紀元例外。尚無第二套真模型時只能標「待驗」，缺材拒絕測試不能當跨套碰撞通過。

| 接口 | 可驗證的方式 |
| --- | --- |
| 鎧甲—鞋子 | 膝甲止口／脛靴上口互不複製；深蹲、跨步、踝屈伸；單穿任一槽無孤立部件 |
| 頭盔—領口 | 上下密封邊分槽，頭轉俯仰及厚領極值；盔不靠另一套護領才遮臉 |
| 肩甲—背飾 | 抬臂／反擊／弯腰包絡与飾品厚度；空背座不包含完整裝置；local偏移有量測界限 |
| 長裙—腿裝 | 既有骨兼容分片／蒙皮、膝髖活動窗；短靴／高靴混穿均檢查，不靠隱整腿 |
| 武器—手／肩腿 | 原右手socket pivot，必要左手輔助以原socket及已有握持方案；攻击／反擊／閃避／敗北姿勢測試 |

原九掛點：`socket.weapon.R`、`socket.weapon.L`、`socket.helmet`、`socket.armor`、`socket.shoes.L`、`socket.shoes.R`、`socket.accessory.back`、`fx.hit.chest`、`fx.root`。後兩個不是擅自新增裝備槽的許可。

遮蔽只由**成功掛載且來源驗證通過的裝備**實際coverage導出，三LOD各別綁定原人物SHA。現有實作按scene instance原indices建立可恢復遮蔽；允許經驗證的局部index選擇，不刪頂點、不改共享CPU buffer、不隱整顆頭／整軀幹。卸槽後重新求其他已穿槽的覆蓋聯集；仍被另一槽覆蓋處不能誤恢復。未知coverage一律不擴大遮蔽。新覆蓋宣告不能直接套用舊已通過Runtime；需要單獨模型／遮蔽測試與施工授權。

失敗、SHA錯誤、缺材、過時generation、換LOD、關閉／context loss應遵守既有逐槽／文字安全回退、restore與dispose；不代換別套、不修改state.equipment／正式裝備效果。真幾何衝突但無安全組合時交付標明限制／不可發布組合，使用已實作的可用回退；**自動依碰撞移槽、調偏移、選mask或靜默拒穿並未因此規格變成現有能力**。取消後禁止舊loader結果掛上，不能新增戰鬥／音訊owner。

## 5. LOD、手機與容量

high保留主分件厚度、關節接口和辨識輪廓；medium減次級刻線／內側不可見細節但保留相同所有權／cover；low保留武器作用端、頭部輪廓、甲型、雙鞋、飾品符號，不把不同套壓成同一色塊。接口及遮面不得隨LOD失效。

用固定3/4戰鬥鏡、正側背、手機直横及約180px人物投影比較；微細符號轉共用材質／法線而不是每螺絲幾何，光效不能吞掉輪廓。材質族／共享來源可复用，但正式名映射不可冒名；貼圖母檔／blend留source，僅批准的必要LOD／貼圖發佈，preload=false、按需載入，不預載210套。不要為每品質強化級複製完整rig／動畫／模型。G007現有15GLB 1,028,860 bytes是基線，不是所有套硬上限；每次交付實測冷熱bytes、CPU/GPU/cache與真手機長測，不能以桌機viewport宣稱iPhone性能。
