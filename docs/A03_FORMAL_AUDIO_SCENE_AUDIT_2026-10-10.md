# 《文明戰線》A03 正式介面／音樂音效情境對照核查
日期：2026-10-10。依 GitHub `main` 程式核對；程式施工與資產完工須分開驗收。

## 規則
1. 音訊名稱跟著真實介面、遊戲模式、正式事件走，不以音效製作批次或模糊的「每個紀元都有一般怪／Boss／災厄」套版。
2. A03 scene catalog 的音樂／環境音只是一份暫定配置；不代表已下載或真正可播。無音檔的介面記 null，禁止假音效。
3. 文字與 3D 標準共享 `CivilizationAudio`，極簡全部靜音。GM 保留四評價按鈕及本機儲存；改名的歷史評價不得刪除。
4. 所有正式戰鬥公式、獎勵、世界狀態、背包、GM 管理及離線樣本不因音樂事件而更動。

## 程式接入範圍（已做 vs 尚未做）
- **已做**：`ui.js` 正式 `render()` 提供主畫面／冒險／角色／背包／強化／專精／指南／設定／災厄／紀錄的 A03 導航情境；`alternateuniverseui.js` 提供異宇宙選擇／戰鬥，`thirdworldarenaui.js` 由正式定相／異相模式接入；`combatfx.js` 的兩條結構化事件提供通用戰鬥開始及結束通知。
- **已做**：高維正式連戰不得因每一次普攻退回虛構的一般戰鬥情境；異宇宙／競技場不能被通用戰鬥事件覆蓋成高維戰線；銀河回顧與宇宙 Boss 也單獨處理。A03 把結束戰鬥後回復探索延遲 3.5 秒視為暫定防重播策略。
- **未做，須後續進入 A04 / 素材補完或 A03 專項修補**：不同高維存在的正式階段演進事件、每個正式 Boss 的識別及獨有配樂、界弦核心操作音效、UI 裝備升級逐按鈕事件、雲端成敗結果、異宇宙 1000 深度各別文化與戰況映射、鏡像／虛空等所有專屬 runtime 的開始結束事件、戰鬥勝敗完整收尾、多軌／淡入淡出／真正 Web Audio 混音、音檔本地化與響度、實機聆聽。
- **保護舊紀錄**：`civilization.gm.audio.review.v1` 不變。舊情境 ID 不做不可靠的同義合併，摘要單獨列「舊分類保留紀錄（未合併到新情境）」，目前新項目的已填寫／未填寫計數不混入舊分類。

## 驗收與完工 Gate
- 跨紀元 GM 八分類及新場景名稱對照正確；無高維 Boss／高維文明災厄／高維懸賞等虛構條目。
- 高維 `fixed/varied`、異宇宙 `select/battle` 不被通用戰鬥事件誤導；文字與 3D 共有音訊。
- 同場景來源音檔可能重用，沒有實際聲音時不能因載入成功宣稱已通過。
- 這份表完成「主要介面／模式語義核對與分類修正」，**不等於 100% 正式事件播放接入、全部素材完工或手機桌機已實機通過**。
