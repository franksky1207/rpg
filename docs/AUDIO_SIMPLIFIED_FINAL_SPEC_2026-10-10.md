# 《文明戰線》共用音訊精簡版・最新已確認規劃（2026-10-10）

> **狀態：使用者討論定案的未施工規格。** 本文件用於下一個對話接續，不代表已完成音檔、正式事件接線或跨裝置驗收。與本文件衝突的舊 A01～A04「每個介面不同曲／73 情境各自配置／200～355 音訊願景」等**音樂產品需求**以本版為準；舊程式與施工紀錄只作技術現況，不可當成新需求。實際遊戲邏輯以重新讀取 GitHub `main` 的正式程式碼為準。

## 一、最後確定的總量：12 種音樂／音效

### 3 首紀元主題音樂（每紀元一首）
1. **銀河紀元**：科幻星際冒險、具有明確旋律的史詩感。
2. **宇宙紀元**：更加壯闊、恢宏、有文明突破規模感。
3. **高維紀元**：神秘超然、有辨識度和旋律，不能只是怪異噪音或單調電子底噪。

**同一紀元所有普通介面共用同一主題。** 角色／背包／裝備／強化／專精／印記／商店／戰線紀錄／冒險選擇／設定等基本 UI 切換，不更換曲目、不每次從曲頭重播。重大演出是否另外插入音樂不在這次 12 種標準規格中，不能自行加檔。

### 3 首全遊戲共用戰鬥音樂
- **普通**：節奏清楚且耐重複。
- **中等**：明顯面對強敵的緊張感。
- **高等**：最高規格的史詩交響＋科幻電子融合。
- **三個紀元共用同三首，絕不擴成每紀元各三首。** 進入正式戰鬥模式時依該模式分級；只有**實際離開**戰鬥模式時回復所屬紀元主題。不因畫面普通 UI 點擊切曲，不因單場結束或計時器而任意中斷連續戰鬥音樂。

### 6 種共用短音效
1. 共用短促介面按鈕／選單切換音。
2. 普通攻擊音。
3. 暴擊音。
4. 閃避音。
5. 重大打擊音（適用 Boss 重擊等**已有正式事件**）。
6. 戰鬥勝利短音效。

**明確取消**：強化成功專屬音效、重大解鎖專屬音效、每種養成或技能各自配聲、每頁面各自配聲；反擊／汲取／穿透／印記等不得因程式有事件就自動要求獨立音檔。沒有確認素材或正式事件的音效可暫時不響，不得捏造。

## 三、播放／介面與技術原則
- **配樂切換：三紀元主題 ↔ 普通／中等／高等戰鬥**；普通頁面維持主題；相同 track 持續播放不重開；正式戰鬥狀態結束才依實際畫面／玩法回主題，避免快速來回與短戰每場重播曲頭。
- 可使用簡短淡入淡出、無縫循環，但不得額外加獨立情境音樂造成規格膨脹。
- 文字與 3D 標準模式共用唯一音訊來源與正式事件，不因演出重複觸發。極簡模式完全靜音。背景／失焦停止，恢復依當前合法情境；音效節流與音訊資源清理保留。
- 戰鬥音效只讀正式結果（如攻擊／暴擊／閃避），不得寫回戰鬥或誤判事件。一般 UI 只用共用輕短按鈕聲，不鋪大量音效。
- **GM 測試中心**以 6 首核心配樂＋6 種音效試聽為主；另以精簡正式模式對應表驗證分級，不再以舊 73 項當成 73 首素材需求。歷史聆聽紀錄應保存，避免當成新版已通過。
- GM 試聽音量只用**一個** 0～100% 滑桿；100% 時所有 GM 試聽播放器 volume=1.0，首次播放、拖曳、切換後一致，不影響正式玩家設定。單音檔／場景試聽現存診斷可重用，但新版不需要複雜多軌 UI。
- 舊 Title 主畫面候選 `dark-title` 經使用者實聽判定為**像噪音、不合格、必須汰換**。不要再把音檔「可載入、LUFS 過關」誤當音樂好聽。其餘候選需真人聆聽比較後才決定留用；目標 12 種音樂／音效目前**尚未備齊或驗收**。
