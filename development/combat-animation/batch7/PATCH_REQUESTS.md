# 第7批必要局部補圖（正式發布阻擋）

## 六張補圖實際驗證後的精確要求（本次優先）

六張補圖已從附件解壓、校驗並無損保存於 `layer-sources/`，不是缺附件。逐套圖證、來源SHA及8項檢查見 `layer-review/review.json` 與 [本次報告](../../../docs/BATCH7_SIX_LAYER_INTEGRATION_REVIEW_2026-10-18.md)。銀河／宇宙body為JPEG，新高維body為RGB PNG，均無Alpha，宇宙灰白棋盤是實際像素。三把weapon均有Alpha且未見明顯人物部件，但整套重組與前手遮擋尚未允收。

**不要重畫三個新角色，也不要再次交付烘焙白底／棋盤的全身圖。** 以 `approved-sources/` 原母圖為畫布，遮罩外的頭盔、胸肩甲、另一側手腳與顏色不動；只補被劍遮住的區域。JPEG壓縮差異不可拿來掩蓋整體幾何改動。

1. **銀河 1254×1254**：現補圖閉合左拳與原持柄指節不同，直接疊完整劍柄會穿過拳面。請交付透明無武器局部修補及遮罩、握柄背後層與前方手指／護腕層，並以原圖座標重組確認腿甲接縫；獨立劍不必另改設計，先按原母圖角度與比例回配。
2. **宇宙 1254×1254**：需要真正透明body Alpha／原座標局部修補，保留銀甲及紫青亮邊，灰白格不可留在邊緣。補圖把原母圖另一側右拳變閉合、右靴外輪廓變寬，這些不是去劍所需，請恢復母圖。另交前手遮擋層及原劍比例原位對照。
3. **高維新版 1024×1536**：只以 `higher_complete_master_v2.png` 為正式母圖。`higher_body_no_weapon_v2.png` 左手（約 x250–375、y690–845）是張開手掌，母圖是握柄；需局部修成母圖的握持指節，保留前手指在柄前、後手掌在柄後的遮擋。獨立武器需以新版護手與劍尖回配；不可把擬合猜測當核定握點。母圖／身體為 RGB PNG，需精準透明 Alpha，保護白金甲與藍光。
4. **高維正式替代規則**：無披風、無星環、無漂浮星體。舊高維全部要求失效；不需披風獨立層、前後星環、四星體、動態披風幀或隱藏披風補繪。只需完整角色、無武器身體、獨立武器，手部遮擋可由身體的精準前景遮罩完成。

輸出分層透明PNG、每層原座標、來源與修補遮罩、各層深度、握點標記及同座標重組圖。**最終握點仍為null**，工程端512診斷圖上的綠／紅十字只是人工估計，請勿照抄當精準值。這些不是再要一批不同角色的生圖，而是修正現有來源的遮擋與Alpha。

以下共同要求僅適用於現行三套設計；高維僅使用v2。

目前三張 approved-sources 母圖（高維只用v2）是唯一角色造型依據。禁止改頭盔、配色、武器、比例、姿勢身份或另畫角色；不要使用 G005/G007/G018。

本次已嘗試影像編輯工具：宇宙去背結果未能證明原像素／色彩不變；銀河去劍試稿改動了腿甲細節；高維去背試稿產生額外大面積光暈。這些試稿未入正式資源，也不構成美術核准。保存在工作階段 generated_images 的試稿不是可重建的正式來源。

## 三紀元共同缺口

請以每套母圖原尺寸、相同座標輸出透明 PNG 分層，工程端再套用 mask-recipe 的統一縮放。只修補被劍遮住的局部；遮罩外應保持原圖不變：

1. 無武器攻擊身體：保留完整閉合握拳、手指、護腕與身體，補齊原先被劍刃／光暈遮住的腿甲。不能只把劍挖空後留洞，也不能保留舊劍殘影。
2. 獨立固定武器：原設計刀刃、護手、柄、柄尾與光暈。被手遮擋的握柄需補齊，武器層不能夾帶手或腿甲。
3. 握點證據：身體與武器同座標重組，確認握拳遮擋深度；攻擊時轉動武器不能露出缺甲／白塊。不得把未核定的握點猜測當正式數值。

銀河：刀刃從左手向畫面右下跨過雙腿。原 PNG 已有 Alpha，但存在 alpha=1 的遠端雜點，須保護真實低強度藍光並清理雜點。

宇宙：JPEG 白底。候選目前保護淺銀甲片，仍有刀刃外圍白色消光殘留；需保留紫青刀刃本身的亮白線與真實光暈，不能把淺甲／刀刃高光一併刪掉。

## 交付與停止條件

至少完整角色、無武器身體、完整武器三種核心層；高維只需完整角色／無武器身體／獨立武器。提供每層來源／修補遮罩／尺寸／圖層深度／握點與重組預覽，先核對造型，再輸出 512×512 透明 WebP。

目前三張 full-candidate.webp 僅是候選完整切圖，acceptedLayers 為空，不能拿來宣稱六動作已完成。必須在圖層可用後才接入現役 SpritePool／WholeSuitActor／Presenter，並驗證新 ID、SHA／快取／GM／手機及桌機。第8批的深度攻擊動作與怪物動畫不在本次。
