# 第7批補圖候選・輕量動畫新版驗收政策（2026-10-18）

> **本檔已由最新輕量標準取代原有發布阻擋判準。** 舊精準補圖要求可作為美術精修參考，**不是第7批發布前必須逐項完成的硬性阻擋**。正式規格參閱 [LIGHTWEIGHT_SPRITE_ACCEPTANCE_2026-10-18.md](../../../docs/LIGHTWEIGHT_SPRITE_ACCEPTANCE_2026-10-18.md)。

## 現有素材
- 三套定稿完整持劍角色母圖可直接作輕量戰鬥動畫主素材；三套無武器身體與獨立武器只是可選候選，不再強制全部拆分。
- 高維只用新版 `higher_complete_master_v2.png`；舊版披風、星環、四星體需求已取消。
- 銀河／宇宙／高維補圖與舊重組稽核留作**歷史診斷與必要時的局部改善線索**，不能繼續把逐指握持、原座標重組或像素級一致視為工程硬性阻擋。

## 本批真正必備
1. 從核准完整角色母圖產生真正具透明Alpha的正式小尺寸WebP。**白底、灰白棋盤或明顯白框絕不可進入正式遊戲**；但邊緣小雜點或局部手部差異在手機尺寸不明顯時允許。
2. 三紀元角色在手機與桌機正式視窗內清楚、朝向與比例合理，無明顯裁切或破洞；高維不加入披風、星環、漂浮星體。
3. 使用現役Presenter／Renderer時鐘，六動作肉眼明顯：待機浮動、攻擊前移、受擊後仰／閃光、閃避側移、回位、死亡傾倒／淡出；**可僅使用完整持劍人物單層**。
4. 選用獨立武器時檢查縮小後手柄不明顯亂飛／穿插；若效果較差，退回完整角色單層，無須額外補圖。
5. 保護正式戰鬥HP／盾／傷害／回合／結算、Save Schema17、極簡／背景／離線、資源解碼／釋放、GM隔離、Cache／發布與安全回退；Actions通過不等於真機發熱已測。

## 非阻擋但可在第8批或日後加強
- 逐指前後手部遮擋、被劍遮蔽腿甲逐像素補繪、身體與武器原座標完全重組、六套獨立手繪動作幀、複雜關節動畫。
- 只有正式小尺寸出現**明顯**視覺問題才開局部修補工作，不得反覆生成整位角色。
