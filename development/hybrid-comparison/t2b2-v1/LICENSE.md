# T2-B2 original prototype asset provenance

New three enemy studies, mesh profiles, panel roughness texture, joint poses,
background, impact shards, contact-shadow source and authoring/baking tools are
original work authored for this repository in this batch. No downloaded model,
stock image, AI concept sheet, external animation, font or borrowed game IP is
included. Released under CC0-1.0:
https://creativecommons.org/publicdomain/zero/1.0/ .

Player/equipment derivatives retain the original repository's CC0-1.0 lineage:
`development/3d-source/characters/player-v1/README.md` and
`development/3d-source/equipment/ancient-ruins-v1/README.md`.
The player topology, weights, rest rig and sockets, and five equipment meshes
remain unchanged; candidate-only actions are newly authored. The original 18
registered GLBs remain byte-identical. The fifteen G007 equipment GLBs are used
by reference, never copied into a candidate player GLB or assigned to G006.

Names/levels/locations remain the official `worldmaps-earth.js` source values.
Development paths are not formal monster IDs. No new skills or numerical
rules derive from these assets. All asset status is prototype/pending; this
license statement is not user art approval or authorization to publish them.

Blender 4.3.2 and Cycles are tools, not bundled runtime dependencies. Babylon
7.54.3 remains the repository's Apache-2.0 dependency; tests load the existing
local copy only. Pillow/numpy are offline packing/QC tools. No new music, audio
player, audio file, account data or cloud credential is present.
