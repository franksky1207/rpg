## 資料與隔離

- `body/`、`full/`：同一個候選規格分別輸出本體與外圍效果；頁面和總覽圖都直接使用這套圖，不各自調色。
- `original/`：原始原型的原檔拷貝。
- `baseline/`：十二隻第二輪認可樣本的固定匯出；重建時如發現 B 不同，腳本會拒絕覆寫。
- `manifest.json`、`data.js`：全部正式身份、候選規格、canonical 對應及來源版本。
- `local-check.json`：本機分類／資源／390px／同宇宙五階／投影快速檢查結果。此環境 Chromium 政策禁止 file://，因此直接雙擊檔案的瀏覽驗證受限；已驗證本機 HTTP 瀏覽。頁面不需外部網路或模組請求，若你的瀏覽器也限制本機檔案，在本資料夾執行 `python3 -m http.server 4173` 後開啟 `http://localhost:4173/` 即可。
- 正式 MonsterActor、正式外觀 resolver、正式圖鑑、GM、映射、數值、存檔、動畫及素材原檔均未修改。這是獨立的待審候選分支，不是第二套已啟用的正式 owner。
- 日後若接受，仍需另行授權把候選納入正式戰鬥 owner，再由正式圖鑑與 GM 引用；本包沒有做該步。
