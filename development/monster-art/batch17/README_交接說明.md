## 重要規則
1. GitHub `franksky1207/rpg` 最新 `main` 是唯一正式來源，開工時先讀最新 SHA，以及 `docs/BOSS_CALAMITY_HIGHER_ART_PLAN_2026-10-21.md`、`docs/MONSTER_ART_PRODUCTION_SOP.md`、`docs/BATCH16_DUNGEON_SPRITES_2026-10-21.md` 與現役程式。
2. **製圖代號 C-01／U-01／H-01 等只是本包暫定代號**，不是已登錄的正式 assetId。高維 H-01 等不可與裝備 H01～H10 混淆。Codex 應核對既有資料後建立不衝突的正式 ID。
3. 30 個 Boss：銀河災厄 10、宇宙災厄 10、高維十王 10。12 張新原型涵蓋 13 個身份，其中 `C-03` 供「終末之眼／先驗之瞳」共用；其餘 17 個沿用既有 21 張原型中的適用圖片。
4. 高維競技場投影原則上共用十王正式圖，不需再新增十張。所有名單均為**計畫映射**，不得假裝正式 resolver 已接通。
5. 玩家左、怪物右。人形／武器型面向左；非方向性環形／核心可合理正面或偏左。不得用 CSS 翻轉去掩蓋原生方向錯誤。
6. Boss 目標本體實際 Alpha 可見高度約玩家 1.5～2.0 倍，表內各別倍率只是**建議值**，不等於已驗收的實際比例。寬型需檢查桌機、手機直向與橫向不裁切、不遮擋角色或血條。保留前兩批地圖及副本的比例政策。
7. 改動限定資產與精確身份映射、共用 MonsterActor 與正式 renderer；不要新增獨立動畫系統或重型特效，也不能修改戰鬥數值、獎勵、存檔、連戰、背景戰鬥與 Fast Catch-up。
8. 資產驗收與正式整合驗收不同：本 ZIP 只證明圖片格式、透明通道、尺寸、留白和 SHA ；未證明 30 身份正式畫面、手機效能、GM 一致性、資源失敗恢復、Actions 或 Pages 通過。
9. 所有 12 張原圖逐張經對話美術審核；H-03 採持秤的審判者，不是獨立純機械秤。H-05 殘像僅為靜態插畫，正式動畫不得恢復半月形光波。
10. Codex 施工請依 SOP 一次整合後，逐身份 × 三視窗、自動化／故障注入／快取重下載／跨模式連戰／GM 真畫面／正式頁面檢查，驗收同一 SHA 的 Actions 和 Pages，真實 iPhone 溫度與耗電另列人工未測，不要自行宣布通過。

01. **C-03｜終末之眼／先驗之瞳**：巨型機械單眼，朝左；銀河／高維共用，需分別配置暗紅金與冷白青藍。檔名 `C-03_eyes_shared`。

08. **H-10｜高維原點**：幾何對稱源核；核心型允許正面。檔名 `H-10_gaowei_yuandian`。
09. **H-06｜維隙之刃**：細長穿透槍刃、空間裂隙，朝左。檔名 `H-06_weixi_zhiren`。
10. **H-07｜逆因輪轉**：金橘與藍紫雙輪盤，反擊象徵。檔名 `H-07_n逆因輪轉`。
11. **H-05｜萬象迴演**：多重錯位殘像與連續攻擊，朝左。檔名 `H-05_wanxiang_huiyan`。
12. **H-08｜噬界深淵**：朝左的深淵生物與巨型吞噬口。檔名 `H-08_shijie_shenyuan`。
