## 整合規則

1. 每類只配一張原型，10宇宙×5稱號＝50層；六類不得重複原型。
2. 圖片全部為512×512真Alpha，怪物面向左；玩家在左、怪物在右。
3. 實戰可見高度必須在玩家的1.5～2.0倍，沿第17批的共用Renderer/GM量測與等比例縮放；本壓縮檔僅驗證圖片本身。
4. 沿用現役MonsterActor、MonsterPool、Renderer、快取及智慧下載。
5. 不更動敵人名稱、數值、稱號、隨機特性、獎勵、存檔及既有第15～17批。
6. 正式整合前重新讀取最新main以及docs/ALTERNATE_UNIVERSE_MONSTER_ART_PLAN_2026-10-22.md、docs/MONSTER_ART_PRODUCTION_SOP.md。
7. 正式圖片資產ID由整合流程核定，AU-01～AU-06是美術規劃代號。
